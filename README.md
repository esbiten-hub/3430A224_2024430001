Funcionamiento y justificación: Al ejecutar el programa lee el archivo .csv y ordena los elementos agregándolos en un árbol balanceado. Luego, inicia el menú con opciones para el usuario: insertar un nodo, buscar un nodo, crear grafo y salir.

Para compilar el código se usa: g++ -Wall Bustamante_Esteban_Act1.cpp -o Act1
Para ejecutar el compilado se ingresa un argumento adicional (el .csv): funcional_GO_minimal.csv.
Usar: ./Act1 funcional_GO_minimal.csv

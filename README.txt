Funcionamiento y justificación: Al ejecutar el programa se crea un tablero con filas y columnas que es rellenado por una cantidad aleatoria de contenedores. A continuación, las opciones del usuario son para gestionar el tablero: mover, remover, y mostrar en pantalla.

Para compilar el código se usa: g++ -Wall Bustamante_Esteban_Act2.cpp -o Act2
Para ejecutar el compilado se ingresan dos numeros: X(filas) e Y(columnas) respectivamente: -> ./Act2 X Y

Consideraciones:
Los números X e Y no pueden superar el valor 10.
El manejo del menu admite solo números; no ingresar letras.
Mirar constantemente el tablero para notar los cambios realizados con cada acción.
